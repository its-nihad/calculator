# Matrix

Matrix is a calculator built with plain HTML, CSS, and JavaScript, with no frameworks or external libraries. It handles addition, subtraction, multiplication, and division, supports chained calculations and keyboard input, and shows an error on division by zero. The whole project lives in a single HTML file, so it is easy to run or host anywhere.

Click this link to view the project: [https://its-nihad.github.io/calculator/](https://its-nihad.github.io/calculator/)
